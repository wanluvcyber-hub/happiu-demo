## 2. โครงสร้างตารางทั้งหมดใน `data/happiu.db` (13 ตาราง + 3 Views)

| ตาราง (Table) | จำนวนข้อมูลเริ่มต้น | หน้าที่หลัก |
|---|---:|---|
| `faculties` | 18 แถว | รายชื่อคณะและวิทยาลัยทั้งหมดของมหาวิทยาลัยนเรศวร (Reference Table) |
| `majors` | 96 แถว | รายชื่อสาขาวิชาในแต่ละคณะ (`faculty_id → faculties.id ON DELETE CASCADE`) |
| `users` | 15 แถว | เก็บบัญชีล็อกอินทั้งหมด (`identifier`, `password_hash`, `role`, `entity_id`) |
| `students` | 4 แถว | ข้อมูลนิสิต, คณะ/สาขา, ทักษะ, ความสนใจ, เวลาว่าง, รูปโปรไฟล์จริง, ตารางเรียน 2 มิติ (`schedule_json`) |
| `employers` | 10 แถว | ข้อมูลร้านค้า/หน่วยงานและสถานะการรับรองผู้จ้าง |
| `jobs` | 36 แถว | ประกาศงานทั้งหมด (แยก `job_type`: `part-time` / `full-time` / `online`, ค่าจ้าง, เวลาทำงานหลายช่วง) |
| `applications` | 3 แถว | ใบสมัครงาน, สถานะคัดเลือก, ข้อเสนอเวลาทำงาน, สถานะรับเข้าทำงาน/ลาออก, รีวิว Work & Grow |
| `work_sessions` | 1+ แถว | บันทึกรอบการเช็กอิน–เช็กเอาต์หลายรอบ พร้อม URL รูปถ่ายลายน้ำเวลาเข้า–ออก, ชั่วโมง, ยอดเงิน และสถานะรับรอง/จ่ายเงิน |
| `chat_messages` | 1+ แถว | ข้อความแชทผูกด้วย `thread_key = student_id::employer_id` (1 ร้าน 1 ห้องแชท ไม่สร้างซ้ำ) |
| `tutors` | 14 แถว | ประกาศรับสอนของติวเตอร์นิสิต (รองรับแก้ไข/ลบ, แบนเนอร์รูปภาพและคำอธิบาย) |
| `tutor_reviews` | 5 แถว | รีวิวและคะแนนดาวจากผู้เรียนสำหรับติวเตอร์ |
| `tutor_requests` | 0+ แถว | คำขอติดต่อเรียนที่ส่งหาติวเตอร์ |
| `reports` | 0+ แถว | เรื่องร้องเรียนงานเสี่ยงและคำชี้แจงจากผู้จ้าง |

### SQL Views สำหรับตรวจสอบและสรุปข้อมูล
| View | ข้อมูลที่ได้ |
|---|---|
| `v_login_accounts` | รายชื่อบัญชีล็อกอินทั้งหมดพร้อมคณะ/ประเภทผู้จ้าง |
| `v_student_work_summary` | สรุปจำนวนรอบ ชั่วโมง และยอดเงิน (รอรับรอง / รับรองแล้ว / จ่ายแล้ว) ของนิสิตแต่ละงาน |
| `v_job_overview` | ภาพรวมประกาศงานพร้อมชื่อร้านและจำนวนผู้สมัคร |
