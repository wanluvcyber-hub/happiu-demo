## 1. บัญชีสำหรับเข้าสู่ระบบทั้งหมด (รหัสผ่านเริ่มต้น: `happiu123`)

หน้าเข้าสู่ระบบใช้ช่องเดียว (**ไม่ต้องเลือกบทบาท**) ระบบจะตรวจสอบบทบาทให้อัตโนมัติจากรหัสประจำตัวหรืออีเมล:

### ฝั่งนิสิต (Student) — 5 บัญชี
| รหัสนิสิต (Identifier) | รหัสผ่าน | ชื่อ–นามสกุล | สถานะข้อมูลและกรณีทดสอบใน DB |
|---|---|---|---|
| `NU-DEMO-001` | `happiu123` | ใบตอง วัฒนกิจ | ครบเกือบทุกสถานะใบสมัคร (`pending` นัดสัมภาษณ์, `offered`, `accepted` + รีวิว 2 ฝั่ง, `resigned` เก็บประวัติรายได้เดิม, `declined`), มี 4 ประกาศติวเตอร์พร้อมคำขอ/รีวิว, แชท 3 ร้าน, และเรื่องร้องเรียน `reviewing` |
| `NU-DEMO-002` | `happiu123` | ธันวา พราวพงศ์ | มีข้อเสนอเวลาทำงาน (`offered`) จากร้านกาแฟ และมีงาน IT Support ที่ **กำลังเช็กอินอยู่ (`checked_in`)** พร้อมกดถ่ายรูปเช็กเอาต์ได้ทันที + มี 6 ประกาศติวเตอร์พร้อมรีวิวและคำขอ |
| `NU-DEMO-003` | `happiu123` | พิมพ์ พิชญกุล | รับเข้าทำงานห้องสมุด (`accepted`) มี **3 รอบลงเวลาครบทุกสถานะ** (`paid` + `approved` + `pending_approval`) พร้อมกดถ่ายรูปเช็กอินรอบที่ 4 หรือแจ้งลาออก + มีเรื่องร้องเรียนที่ปิดเคสแล้ว (`closed`) |
| `NU-DEMO-004` | `happiu123` | นที แสนดี | บัญชีนิสิตใหม่ (ยังไม่ตั้งค่าทักษะ/ไม่มีใบสมัคร) เหมาะเทสหน้าเพิ่มทักษะ 2 ขั้นตอนและสมัครงานตั้งแต่ศูนย์ |
| `66310001` | `happiu123` | ปันปัน ศิริวัฒน์ | ตัวอย่างรหัสนิสิตจริง 8 หลัก (วิศวกรรมคอมพิวเตอร์ ปี 3) มีใบสมัคร `pending`, `withdrawn`, `offer_declined`, แชท 1 ห้อง และเรื่องร้องเรียนใหม่ (`new`) |

> หรือกดแท็บ **สร้างบัญชีใหม่** ในหน้าเข้าสู่ระบบเพื่อสมัครด้วยรหัสนิสิตจริง (เช่น `6631xxxx`) ระบบจะบันทึกลงตาราง `users` และ `students` ทันที

## 2. โครงสร้างตารางทั้งหมดใน `data/happiu.db` (13 ตาราง + 3 Views)

| ตาราง (Table) | จำนวนข้อมูลเริ่มต้น | หน้าที่หลัก |
|---|---:|---|
| `faculties` | 18 แถว | รายชื่อคณะและวิทยาลัยทั้งหมดของมหาวิทยาลัยนเรศวร (Reference Table) |
| `majors` | 96 แถว | รายชื่อสาขาวิชาในแต่ละคณะ (`faculty_id → faculties.id ON DELETE CASCADE`) |
| `users` | 16 แถว | เก็บบัญชีล็อกอินทั้งหมด (`identifier`, `password_hash`, `role`, `entity_id`) |
| `students` | 5 แถว | ข้อมูลนิสิต, คณะ/สาขา, ทักษะ, ความสนใจ, เวลาว่าง, รูปโปรไฟล์จริง, ตารางเรียน 2 มิติ (`schedule_json`) |
| `employers` | 10 แถว | ข้อมูลร้านค้า/หน่วยงาน ครบทั้ง 3 สถานะ (`verified`, `pending`, `update`) |
| `jobs` | 36 แถว | ประกาศงานทั้งหมด ครบ 3 ประเภท (`part-time`, `full-time`, `online`) และครบ 6 สถานะ (`live`, `draft`, `review`, `edits`, `rejected`, `paused`) |
| `applications` | 11 แถว | ใบสมัครงานครบทุก 7 สถานะ (`pending`, `offered`, `accepted`, `resigned`, `declined`, `withdrawn`, `offer_declined`) และรีวิว 2 ฝั่ง |
| `work_sessions` | 7 แถว | รอบเช็กอิน–เช็กเอาต์ครบทุก 4 สถานะ (`checked_in`, `pending_approval`, `approved`, `paid`) พร้อมลายน้ำวันเวลา |
| `chat_messages` | 11 แถว | ข้อความแชท 5 ห้องร้านค้า ผูกด้วย `thread_key = student_id::employer_id` (1 ร้าน 1 ห้องแชท ไม่สร้างซ้ำ) |
| `tutors` | 14 แถว | ประกาศรับสอนของติวเตอร์นิสิต (รองรับแก้ไข/ลบ, แบนเนอร์รูปภาพและคำอธิบาย) |
| `tutor_reviews` | 8 แถว | รีวิวและคะแนนดาวจากผู้เรียนสำหรับติวเตอร์ |
| `tutor_requests` | 5 แถว | คำขอติดต่อเรียนที่ส่งหาติวเตอร์ |
| `reports` | 3 แถว | เรื่องร้องเรียนงานเสี่ยงครบทุก 3 สถานะ (`new`, `reviewing` + คำชี้แจงผู้จ้าง, `closed`) |

### SQL Views สำหรับตรวจสอบและสรุปข้อมูล
| View | ข้อมูลที่ได้ |
|---|---|
| `v_login_accounts` | รายชื่อบัญชีล็อกอินทั้งหมดพร้อมคณะ/ประเภทผู้จ้าง |
| `v_student_work_summary` | สรุปจำนวนรอบ ชั่วโมง และยอดเงิน (รอรับรอง / รับรองแล้ว / จ่ายแล้ว) ของนิสิตแต่ละงาน |
| `v_job_overview` | ภาพรวมประกาศงานพร้อมชื่อร้านและจำนวนผู้สมัคร |
