# HappiU — ระบบหางานพาร์ตไทม์และหาติวเตอร์สำหรับนิสิตมหาวิทยาลัยนเรศวร (มอนอ)

แพลตฟอร์มเว็บต้นแบบแบบโต้ตอบได้เต็มรูปแบบ (**Interactive Clickable Prototype**) สำหรับนิสิต ผู้จ้าง และเจ้าหน้าที่มหาวิทยาลัยนเรศวร (มน.) ออกแบบด้วยธีม **iPhone (Liquid Glass) × มอนอ** (สีแสด–เทา มน. ผสมสีม่วงดอกเสลาและเขียวมิ้นต์) ใช้งานได้ทันทีโดยไม่ต้องติดตั้งไลบรารีหรือรันขั้นตอน Build

---

## จุดเด่นและฟีเจอร์หลัก

### 1. ฝั่งนิสิต (Student)
- **Smart Job Matching (`ความเข้ากันกับคุณ %`):** คำนวณคะแนนความเหมาะสมของงานจากทักษะ ความสนใจ และเวลาว่าง พร้อมแถบวัดระดับและเหตุผลแนะนำเฉพาะบุคคล
- **ตรวจเวลาชนตารางเรียนอัตโนมัติ:** เปรียบเทียบกะงานกับตารางเรียนในเมนู **ตารางเรียนและงาน** ป้องกันการสมัครกะที่ชนเวลาเรียน
- **หางานพาร์ตไทม์ครบ 34+ ตำแหน่ง:** แยกหมวด `ในมหาวิทยาลัย`, `รอบมหาวิทยาลัย (หน้ามอ)`, `ออนไลน์`, กรองตามช่วงเวลา และดูแผนที่/ข้อมูลผู้จ้างที่ผ่านการรับรอง
- **ระบบหาติวเตอร์ & ลงประกาศรับสอน:** ค้นหาติวเตอร์นิสิต มน. 14+ รายการด้วยปุ่มกรองหมวดวิชาด่วน ส่งคำขอติดต่อเรียน หรือลงประกาศรับสอนเองได้
- **ห้องแชทพร้อมชุดอีโมจิ & สติ๊กเกอร์มอนอ:** คุยตกลงกะงานกับผู้จ้างได้โดยตรง พร้อมแถบส่งด่วน, ชุดอีโมจิ 72 ตัว, **สติ๊กเกอร์มอนอ 8 ลาย**, Jumbo Emoji และเอฟเฟกต์พลุอีโมจิ
- **กะงาน รายได้ และโปรไฟล์บัตรนิสิตดิจิทัล:** เช็กอิน–เช็กเอาต์กะงาน, ดูสรุปรายได้, พอร์ตฟอลิโอ Work & Grow และแก้ไขทักษะ/รูปโปรไฟล์ได้ทันที
- **แจ้งงานเสี่ยงและเรื่องร้องเรียน:** ส่งเรื่องร้องเรียนพร้อมติดตามความคืบหน้าข้ามบทบาท

### 2. ฝั่งผู้จ้าง (Employer)
- **จัดการประกาศงานและสลับบัญชีผู้จ้าง:** สร้างประกาศงานใหม่ (รองรับทั้งค่าจ้างรายชั่วโมงและงานเหมา + หลายกะต่อประกาศ), บันทึกฉบับร่าง และส่งให้เจ้าหน้าที่ มน. ตรวจสอบ
- **จัดการผู้สมัคร & ข้อเสนอกะ:** ดูคะแนนความตรงกันของผู้สมัคร, อัปเดตสถานะ (เช่น นัดสัมภาษณ์), ตอบแชท และส่งข้อเสนอกะงาน
- **รับรองชั่วโมงและประเมินงาน (Work & Grow):** ตรวจเวลาทำงานของนิสิต รับรองชั่วโมง ยืนยันการจ่ายค่าตอบแทน และให้คะแนนประเมิน
- **ชี้แจงเรื่องร้องเรียน:** ตอบคำชี้แจงต่อเจ้าหน้าที่ มน. ได้ในระบบ

### 3. ฝั่งเจ้าหน้าที่มหาวิทยาลัย (Admin มน.)
- **ตรวจและอนุมัติประกาศงาน:** ตรวจสอบประกาศใหม่ อนุมัติขึ้นหน้าหางานจริง ส่งกลับให้แก้ไข หรือระงับประกาศ
- **ตรวจสอบและรับรองผู้จ้าง:** รับรองสถานะผู้จ้าง/ร้านค้ารอบมอและหน่วยงานในมหาวิทยาลัย
- **จัดการเรื่องร้องเรียน:** รับเรื่อง ตรวจหลักฐาน ขอคำชี้แจง และปิดเคส

## วิธีรันโปรเจกต์บนเครื่อง (Local Development)

โปรเจกต์ใช้ HTML/CSS/JavaScript มาตรฐาน 100% ไม่ต้องติดตั้ง Dependency เพียงเปิดผ่าน Local Web Server วิธีใดวิธีหนึ่งดังนี้:

### วิธีที่ 1: ใช้ Python (แนะนำ)
```bash
python3 -m http.server 8081 --bind 127.0.0.1
```
จากนั้นเปิดเบราว์เซอร์ไปที่: **http://127.0.0.1:8081/** (จะเปิดไฟล์ `index.html` โดยอัตโนมัติ)

### วิธีที่ 2: ใช้ Node.js (`npx serve`)
```bash
npx serve . -l 8081
```

### วิธีที่ 3: ใช้ VS Code Live Server
คลิกขวาที่ไฟล์ `index.html` แล้วเลือก **Open with Live Server**

> **เคล็ดลับ:** ข้อมูลการทดสอบทั้งหมดบันทึกอยู่ใน `localStorage` ของเบราว์เซอร์ หากต้องการล้างข้อมูลกลับเป็นค่าเริ่มต้น สามารถกด **ออกจากระบบ → เข้าสู่ระบบ → เริ่มเดโมใหม่** ได้ทันที
